# Estrutura de Dados III

## Clonar

```bash
git clone https://github.com/ellii0-0/Trabalho-Pratico-Estrutura-de-Dados-3
cd ./Trabalho-Pratico-Estrutura-de-Dados-3
```

## Compilar

```bash
make all
```

## Executar

```bash
make run
```

## Limpar

```bash
make clear
```

## Address Sanitizer

```bash
make all BUILD_MODE=DEBUG ASAN=1
```
